# 甲状腺癌后续研究分析包

本文件夹基于目录内 2026-07-19 至 2026-07-28 的 6 份文献调研，并以 2026-07-28 的报告为主，形成可直接启动的研究设计。

## 文件

- `01_研究方向与证据缺口.md`：方向比较、主方向选择和检索记录。
- `02_研究方案_MGST1_APOE_LNM.md`：推荐课题的完整、可证伪研究方案。

## 建议的起步顺序

1. 先做公共单细胞数据复分析，设置“MGST1 高 / APOE 低”状态的预注册式判定标准。
2. 仅在该状态与 LNM 的关联跨数据集重复后，启动本地组织队列的双标验证。
3. 若联合状态不稳定，按方案中的预设分流转为“并行而非同一状态”的比较研究，不强行叙述为同一细胞亚群。

本分析为研究规划，不构成临床诊疗建议；涉及人组织、随访及动物实验时，须在实施前取得相应伦理审批。
